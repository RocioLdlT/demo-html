# HTML Module
Inicio del modulo de HMTL

Nuestra web puede ser SPG o MPA. Incluso una mezcla de ambas donde hagamos scroll en nuestra página principal y tengamos un menu donde repartamos las secciones.

Para redirigir estas páginas podemos diferenciar entre enlaces relativos y enlaces absolutos.

### Enlaces relativos

Son los encales que usamos para realizar scroll o rutas internas con un `#home` o `./desserts`, `../proyects`(un id donde ya asociado a la propia sección `id = home`o una ruta de un archivo de una carpeta).
*Si la ruta es hacia un `.html` (y solo hay uno en esa carpeta a la que estamos redirigiendo) puedes no poner su nombre y redirigir tan solo con un `./`.

### Enlaces absolutos

Son los asociados a rutas externas de mi web. 
Por este motivo ponemos un target=_blank a nuestros contactos de nuestras redes sociales, para que este asociada a nuestra web.
